# Decisions

Choices made where the brief left room. Newest last.

| # | Milestone | Decision | Why |
|---|---|---|---|
| 1 | M0 | Tauri **2.12** (stable), not the 3.0 alphas on crates.io. | The brief fixes Tauri 2; alphas are not production-ready. |
| 2 | M0 | Fuzzy matching uses `nucleo-matcher` (the matcher crate from the nucleo project) instead of the `nucleo` crate. | Quick open ranks a list synchronously per keystroke; `nucleo`'s threaded streaming worker adds complexity we do not need yet. Swap if lists exceed ~100k entries. |
| 3 | M0 | Heavy dependencies (`typst`, `syntect`, `notify`, `ammonia`, `grep-*`, `directories`) are added in the milestone that uses them. | Keeps M0 compile times and CI fast; each is still the planned crate. |
| 4 | M0 | `crates/cli` is a library (clap definitions + headless runner) plus a small `markdraft-cli` binary. The app binary parses the same CLI. | One parser for both entry points. Release builds on Windows use the GUI subsystem and have no console, so headless commands there should use `markdraft-cli`. |
| 5 | M0 | Commands are declared in `build.rs` (`AppManifest::commands`) and granted one by one in `capabilities/default.json`. | A command the capability does not list cannot be invoked, which keeps the WebView's reach explicit. |
| 6 | M0 | Path scoping to workspace roots is enforced in Rust by our own commands (M1), not by `tauri-plugin-fs` scopes. | The WebView has no file-system plugin at all; every path a command receives is checked against the open roots. |
| 7 | M0 | CSP allows `'unsafe-inline'` for **styles only**. | KaTeX and Mermaid emit inline styles; scripts stay `'self'`. |
| 8 | M0 | A launch path is held in `AppState` and drained by the UI with `take_open_request`; later paths arrive as `app://open-path` events. | An event emitted before the WebView attaches its listener would be lost. |
| 9 | M0 | Unknown command-line flags are ignored instead of failing launch. | macOS and some launchers inject flags (`-psn_*`); a file association must never fail to open the app. |
| 10 | M0 | Bundle identifier `app.markdraft.desktop`. | Must be reverse-DNS and must not end in `.app` on macOS. Change before the first signed release if you own a domain. |
| 11 | M0 | Mobile icons generated by `tauri icon` are deleted. | Desktop only (non-goal). |
| 12 | M0 | Licence set to `MIT OR Apache-2.0` in manifests, **provisionally**. | The proposal left licensing open; change `Cargo.toml` and README if you choose otherwise. |
| 13 | M1 | The tree is built in the UI from a flat list of nodes streamed by Rust (`tree://batch`, 400 nodes per batch, flushed every 30 ms). | First rows paint after ~7 ms on 10,000 files; the UI owns sorting, filtering and expansion without round trips. |
| 14 | M1 | Titles are read from the first 16 KB of each file during the scan. | Keeps a 10k-file scan under 100 ms; a title after 16 KB of text is unusual. |
| 15 | M1 | `.gitignore` is honoured in plain folders too (`require_git(false)`); hidden folders are skipped. | Docs folders are often outside a repo or inside one; behaviour should not change. |
| 16 | M1 | Live watcher events honour only root-level ignore files; a rescan applies nested ones. | Matching nested ignore files per event is costly; rescans are rare. |
| 17 | M1 | Local images are served through a custom `mdasset` protocol that only returns image file types. Remote `https:` images are allowed in the preview. | The WebView has no file access; badges and remote images are common in READMEs. |
| 18 | M1 | Raw HTML in Markdown is allowed through comrak and then sanitised with `ammonia` (no scripts, no event handlers, checkbox-only inputs). | Real-world docs use `<details>`, `<br>`, `<img width>`. |
| 19 | M1 | Syntax highlighting emits CSS classes (`hl-*`); the UI injects the light or dark palette. | Theme switches without re-rendering documents. |
| 20 | M1 | Documents are edited with `\n` line endings; saves restore CRLF, BOM and encoding (UTF-8, UTF-16 LE/BE, Windows-1252). | Editing must never silently reformat a file. |
| 21 | M1 | Saves pass the modification time read at load; a mismatch returns a conflict instead of overwriting. Our own writes are recorded so the watcher ignores their echo. | Prevents lost updates from sync tools and other editors. |
| 22 | M2 | One CodeMirror view with an `EditorState` per tab. | Per-tab undo history and selection, without one editor DOM per tab. |
| 23 | M2 | Changes from disk are applied as one minimal edit (common prefix/suffix kept), undoable. | Keeps scroll and cursor; a reload can be undone. |
| 24 | M2 | Tree drag-to-move uses pointer events, not HTML5 drag and drop. | Tauri's native file drop (needed to drop folders onto the window) disables HTML5 DnD on Windows. |
| 25 | M2 | Full-text search uses the `regex` crate over the indexed documents on all cores, instead of `grep-searcher`. | Documents are small and already indexed; simpler code, same speed for this use. |
| 26 | M2 | Autosave on by default (1 s after typing stops, and on blur / tab switch). | Matches modern editors; conflicts are still detected. |
| 27 | M3 | Settings and per-workspace session state are JSON blobs owned by the UI and stored by Rust in the app-data folder; session keys hash the sorted root paths (FNV-1a). | The UI shape can evolve without Rust changes; keys are stable across Rust versions. |
| 28 | M3 | Paths outside the open folders can only be written if the user picked them in a save dialog during this run (exports, workspace files). | Keeps the IPC surface safe even if the WebView were compromised. |
| 29 | M3 | PDF export compiles Typst in-process with bundled fonts (Inter, Source Serif 4, JetBrains Mono NL, New Computer Modern Math; 3.65 MiB) and no system fonts, network or clock. | Identical, reproducible output on every OS. |
| 30 | M3 | LaTeX math is converted with `mitex`; its Typst scope is vendored offline. Formulas that fail fall back to their source. | No network at export time; a bad formula never breaks an export. |
| 31 | M3 | Mermaid diagrams are rendered by the UI (plain-text labels) and passed to the exporter as SVG; the CLI prints their source instead. | The exporter has no JavaScript engine. |
| 32 | M3 | Minimum Rust version raised to 1.92. | Required by typst 0.15. |
| 33 | Git | Git access is read-only, through `git2` with vendored libgit2 and no network features. | Reviewing changes needs no writes; identical builds on every OS. |
| 34 | Git | Diffs are shown per Markdown block (paragraph, list item, heading, table row) with word-level marks inside edited blocks, plus a classic line view. Edited prose is rendered as formatted Markdown with insert/delete marks carried through the renderer as private-use characters. | Writers review prose as tracked changes, not as patches. |
| 35 | Git | Moves are detected for identical blocks of three or more words; re-wrapped paragraphs and whitespace-only edits count as unchanged. | Avoids noise from reflowing text. |
| 36 | App | `freezePrototype` is off. | With it on, a bundled UI library failed at startup ("Cannot assign to read only property valueOf"); scripts stay limited to `'self'` by the CSP. |
| 37 | App | After a WebView reload the UI reattaches to the folders Rust still has open and rescans them. | Recovery without losing the session. |
| 38 | M3 | Release builds use `opt-level = "z"`. | NSIS installer 14.25 → 13.25 MiB; a 6-page PDF export still takes ~0.34 s end to end. |
| 39 | M3 | KaTeX is pinned to the 0.18 line Mermaid depends on. | Avoids bundling two copies. |
| 40 | Extra | Pasted or dropped images are stored in an `assets/` folder next to the document with a slugged, unique name, and linked relatively. | Keeps documents portable and the folder tidy. |
| 41 | Extra | Backlinks (Outline pane) come from relative Markdown links that resolve to the document and wiki links naming its file or title. | Notes collections are navigated as much by "what points here" as by the tree. |
